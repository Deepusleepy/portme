# Phase 3 — Port everything

**Prerequisites.** Phase 2 approval matched to the actual conversation; approved amendments/batch plan; current manifest/check-input authorization bundle digest, command, and declaration authorization; live per-referee-class accidental-invocation guardrail receipts before fan-out.
**Inputs.** Frozen/amended manifest plus approved authorization-bundle SHA-256, contract, map, rules, gaps, unit packets, judge slices, approved model plan, status header.
**Permitted mutations.** Implement owned target paths, add exact-site port markers, and apply confirmed fixes. Worker scope excludes rulebook, judge, and expensive-referee controls; denies reduce accidents but are not a security boundary.
**Outputs.** Checked units, review/tiebreaker receipts, skip reason codes, blocked-unit proposals, marker scan, cost log, drift policy.
**Gate evidence.** Current manifest/check-input authorization bundle digest versus conversation authorization, queue counts from authorized checks, broken-output probes, consumer-path/dependent-integration results for changed signature or adapter boundaries, sampling minimum, disputes, exception gates, approved deferrals, disposal audit, raw receipts.
**Stop condition.** Pause affected work at a third recurrence; otherwise set `awaiting-gate-signoff` and stop when every unit is done or explicitly deferred. A leaf-only green check cannot close a changed signature/adapter boundary.
